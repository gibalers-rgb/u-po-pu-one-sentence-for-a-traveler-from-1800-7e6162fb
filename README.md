A program that writes one sentence (at most 200 characters) to
`/output/entry.txt`, explaining the modern internet to someone arriving
from the year 1800 — using only things a person from 1800 already knows:
a road, a library, a post office, a marketplace, letters, books, and
spoken words. No word coined after their time.

Run with Node 22:

```sh
node main.ts
```

The sentence:

> Picture a single road joining every library, post office, and marketplace in the world, so a letter, a book, or a spoken word can reach any door faster than a breath, day or night.
